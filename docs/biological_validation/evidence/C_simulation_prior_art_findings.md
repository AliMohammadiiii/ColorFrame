## 6. Baselines
- **Pyrodigal**: v3.7.1 (PyPI, GitHub release 2026-03-07), GPL-3.0-or-later. Gives the same results as Prodigal v2.6.3+31b300a. Has `meta=True` mode (the Prodigal -p meta pre-trained models, plus custom models since v3). Start codon types are ATG/GTG/TTG, or "Edge" for partial genes. Gene objects expose `partial_begin`, `partial_end`, `start_type`, `rbs_motif` and `translate()`. Writers: `write_gff`, `write_genes`, `write_translations`, `write_genbank`, `write_scores`. `min_gene` (90) and `min_edge_gene` (60) are configurable, as are `closed` and `mask`. **V**: pyrodigal/README.md, lib.pyi:161-300,392-424, lib.pyx:227,1490,2681-2691.
- **ggCaller**: the canonical repo is **bacpop/ggCaller** (samhorsfield96/ggCaller is a fork). Latest **v1.5.2** (2026-08-31), MIT, bioconda 1.5.2. v1.5.0 changed the default to "generate GFF files only" and removed the built-in Panaroo clustering. The paper used v1.3.4, which still had Panaroo. Inputs: `--refs` (assemblies), `--reads`, or a prebuilt Bifrost `--graph x.gfa --colours x.color.bfg` (with `--refs` / `--not-ref` to say which colours are assemblies). k is 31 by default, which is also the maximum. Requires bifrost>=1.3.5. Codons: start ATG/GTG/TTG, stop TAA/TGA/TAG (codons.json). Output: predicted genes (nt and aa FASTA) and **one GFF per input genome (colour)**, so calls are reported per colour/genome, plus GFA/colour files and FM-index files. Query mode maps sequences onto an annotated graph. The usage docs still mention Panaroo and `--gene-finding-only` and may be stale relative to v1.5.0 (**U**). **V**: ggcaller/releases_notes.txt, usage.rst, advanced.rst, codons.json, README.md.

## 7. Can "the full candidate sequence occurs contiguously in a genome present in sample s" be decided?
**Yes, for CAMISIM output and for the CAMI II toy HMP (V).**
1. Per-sample genome set: genomes with abundance > 0 in `distribution_i.txt` / `abundanceN.tsv`. Equivalently, genomes that have a BAM in `sample_i/bam/` or appear in `reads_mapping.tsv`.
2. Genome sequences: `source_genomes/*.fa` (CAMISIM 2), or `genomes/*.fa` via `genome_to_id.tsv` (toy HMP).
3. Search both strands for an exact contiguous match.

Caveats:
- "Present in sample" is not the same as "sequenced in sample". Use the per-sample GSA (coverage ≥1 intervals, with coordinates in `gsa_mapping`) or the BAM coverage for a read-supported variant.
- Genomes carry plasmids as extra records (BinBencher note).
- Gene-level truth (CDS coordinates, frames, starts) is not part of CAMI. It has to come from NCBI annotations of the GCA accessions, or from a re-annotation, which would be a prediction and not truth.
